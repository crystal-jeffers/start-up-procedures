# Commissioning

Functional testing with the Commissioning (Cx) agent. Only applies when commissioning is in scope.

> Note: If applicable. Confirm with the PM before you start.

## Steps

### Prepare
1. Make a final pass on all documents before turnover.
2. Obtain the FTS (Functional Test Scripts) from the Cx agent or MEP coordinator.
3. Make notes on SI scripts for an internal review.
4. Confirm all documentation has been turned over to the GC and Cx agency before FPTs (Functional Performance Tests).
5. Attend meetings with the Cx agent as needed.

### Test
6. Verify the functional test can be performed under load.
7. Make sure all required testing equipment is calibrated and certified per spec.
8. Follow the FTS and complete the Cx documents with signatures as needed.

### Close out
9. Return the system to regular operation after the commissioning process is complete.
10. Once Cx activities are complete, review any changes or needed punch list items.
