# Pre-Start

Get the crew, the plan, and the paperwork lined up before any equipment starts.

## Steps

### Set the team
1. Gather all Start-Up personnel and set expectations (safety, start and finish times, path of information, and team hierarchy).
2. Discuss short-term and long-term goals.
3. Set up personnel per task for the entire week with contingency plans (pre-task planning and workable backlog).

### Plan and verify
4. Break systems down into priorities and schedules.
5. Verify all certifications.
6. Confirm power dates are still valid.
7. Secure the Clean and Flush plan (include a contingency plan, riser diagram, and shop drawing on each floor with isolation valves and bypasses marked if possible).
8. Review the controls SOO. Make sure you've received all updates.

### Clear the path to startup
9. Start Pre-Functional activities (these must be completed before startup).
10. Verify there are no problems or issues that could prevent the startup process.
11. Document outstanding issues or discrepancies that may affect or prevent equipment startup.
