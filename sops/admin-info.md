# Admin Info
Type: Checklist

Work with the PM team to acquire or create the project information and items listed below. Your ticks are saved on this device, so you can work through the list over a few days.

## Job basics
- [ ] Job address, site map, and parking requirements.
- [ ] Job number, cost codes, non-start-up task codes, and folder links.
- [ ] Job site contact list.
- [ ] Project file in Forma ([see template](#add-template-link)).
- [ ] Job-specific safety requirements.

## Project documents
- [ ] Project information:
  - BOD
  - Equipment Submittals
  - IO&Ms
  - Drawings
  - All SOO
  - Project Schedule
  - Vendor List
- [ ] Project milestones, critical schedule dates, and project priorities.
- [ ] Vendor startup responsibilities and SI prerequisites.

## Start-up readiness
- [ ] Verify the correct startup documentation is available.
- [ ] Verify startup docs reflect actual equipment.
- [ ] Get access to all job-specific software platforms (scheduling, documentation, tracking, and so on) and request access for the Start-Up Superintendent and all site Start-Up personnel.
- [ ] Develop or review the Clean and Flush plan.
- [ ] Review the Fire Life Safety plan.
- [ ] Schedule internal Start-Up meetings with the PM and proper trades (for example, Electrical and Controls contractors).
