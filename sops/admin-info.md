# Admin Info

Work with the PM team to acquire or create the project information/items listed below.

## Project Setup Checklist

<ol class="chunked-list">
<li>Job address, site map, and parking requirements.</li>
<li>Job number, cost codes, non-start-up task codes, and folder links.</li>
<li>Job site contact list.</li>
<li>Project file in Forma (see template: insert link here).</li>
<li>Job-specific safety requirements.</li>
<li>Project information:
<ul>
<li>BOD</li>
<li>Equipment Submittals</li>
<li>IO&Ms</li>
<li>Drawings</li>
<li>All SOO</li>
<li>Project Schedule</li>
<li>Vendor List</li>
</ul>
</li>
<li>Project milestones (critical schedule dates) and project priorities.</li>
<li>Vendor startup responsibilities and SI prerequisites.</li>
<li>Startup and commissioning documentation:
<ul>
<li>Verify the correct startup documentation is available.</li>
<li>Verify startup docs reflect actual equipment.</li>
<li>Get access to all job-specific software platforms (scheduling, documentation, tracking, etc.) and request access for the Start-Up Superintendent and all site Start-Up personnel.</li>
<li>Develop or review the Clean and Flush plan.</li>
<li>Review the Fire Life Safety plan.</li>
</ul>
</li>
<li>Schedule internal Start-Up meetings with the PM and proper trades (for example, Electrical and Controls contractors).</li>
</ol>
