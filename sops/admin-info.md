# Admin Info

Work with the PM team to acquire or create the project information/items listed below.

## Project Setup Checklist

1. Job address, site map, and parking requirements.
2. Job number, cost codes, non-start-up task codes, and folder links.
3. Job site contact list.
4. Project file in Forma (see template: insert link here).
5. Job-specific safety requirements.
6. Project information:
   - BOD
   - Equipment Submittals
   - IO&Ms
   - Drawings
   - All SOO
   - Project Schedule
   - Vendor List
7. Project milestones (critical schedule dates) and project priorities.
8. Vendor startup responsibilities and SI prerequisites.
9. Startup and commissioning documentation:
   - Verify the correct startup documentation is available.
   - Verify startup docs reflect actual equipment.
   - Get access to all job-specific software platforms (scheduling, documentation, tracking, etc.) and request access for the Start-Up Superintendent and all site Start-Up personnel.
   - Develop or review the Clean and Flush plan.
   - Review the Fire Life Safety plan.
10. Schedule internal Start-Up meetings with the PM and proper trades (for example, Electrical and Controls contractors).
